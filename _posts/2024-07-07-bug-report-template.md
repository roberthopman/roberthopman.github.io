A good bug report can save hours of debugging. 

What the template does between the reporter and the developer:

![A data flow diagram with three lanes, Reporter, GitHub and Developer, and four steps, Report, Template, Issue and Debug. A loose report from the reporter, quoted as the save button breaks, goes as a new issue into the bug_report.md template in .github/ISSUE_TEMPLATE, which is highlighted. The template asks for expected and actual behavior and steps, GitHub stores the answers as a structured issue with given, when, then, severity and environment, and the developer reproduces and fixes the bug with the steps already in hand.](/assets/images/bug-report-template-recap.svg)

This can be used as (Github) template for issues. 

Add file in repo_name/.github/ISSUE_TEMPLATE/bug_report.md
